# Wazuh SIEM Lab: Querying and Investigating Security Events

**Tool:** Wazuh (Open-source SIEM/XDR Platform)
**Dataset:** Buttercup Games mail server and web application logs

---

## Project Description

In this lab, I used the Wazuh SIEM platform to investigate potential security issues with a mail server at Buttercup Games, an e-commerce company. I performed queries to search through over 100,000 indexed log events, identified failed SSH login attempts targeting the root account, and analyzed log data from multiple network hosts.

---

## Environment Overview

| Host | Description |
|---|---|
| mailsv | Buttercup Games' mail server |
| www1 | Web application server 1 |
| www2 | Web application server 2 |
| www3 | Web application server 3 |
| vendor_sales | Retail/financial transaction logs |

**Key log file:** `/mailsv/secure.log` — contains authentication and authorization attempts on the mail server.

---

## Task 1: Confirm Data Ingestion

Searched all indexed events across all time:

```
*
```

**Result:** Over 100,000 events retrieved from the buttercup-games* index.

---

## Task 2: Filter Events by Host

Narrowed search to events from the mail server only:

```
host.keyword: mailsv
```

**Result:** Over 9,000 events generated by the mail server.

---

## Task 3: Investigate Failed SSH Logins for Root

Searched for failed SSH login attempts targeting the root account:

```
host.keyword: mailsv AND (fail* OR failed) AND root
```

**Result:** Over 300 events — indicating a high volume of failed SSH login attempts targeting the root account on the mail server.

---

## Key Findings

| Query | Result |
|---|---|
| Total events in index | Over 100,000 |
| Events from mailsv | Over 9,000 |
| Failed SSH logins for root | Over 300 (More than 100) |
| Host with financial data | vendor_sales |
| Field identifying network host | host |

---

## Analysis

The large number of failed SSH login attempts (300+) targeting the root account on the mail server is a strong indicator of a **brute force attack**. This pattern suggests that a malicious actor is repeatedly attempting to guess the root password to gain unauthorized access to the mail server.

**Recommended actions:**
- Disable direct root SSH login
- Implement fail2ban or similar brute force protection
- Enable MFA for SSH access
- Review /mailsv/secure.log for any successful logins following the failed attempts

---

## Summary

In this lab, I used Wazuh to ingest and search through log data from multiple hosts at Buttercup Games. Using wildcard queries and field-based filters, I successfully identified over 300 failed SSH login attempts targeting the root account on the mail server — a strong indicator of a brute force attack in progress. This activity reinforced the importance of SIEM tools in quickly identifying suspicious patterns across large volumes of log data.
