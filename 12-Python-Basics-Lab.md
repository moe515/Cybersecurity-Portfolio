# Python Basics Lab: Introduction to Python for Security

**Language:** Python 3  
**Environment:** Jupyter Notebook

---

## Project Description

In this lab, I was introduced to Python programming in a notebook environment. I practiced writing code comments, using the `print()` function to display strings, and working with both markdown and code cells. Python is a critical tool for security analysts to automate tasks, analyze data, and build security tools.

---

## Task 1: Markdown Cell

Wrote a description in a markdown cell:

```
I am a security analyst learning Python to automate security tasks.
```

---

## Task 2: Running a Code Cell

```python
# This cell displays "Hello world!"
print("Hello world!")
```

**Output:** `Hello world!`

The `print()` function outputs whatever string is passed inside the parentheses.

---

## Task 3: Code Comments

```python
# In Python, comments do not get displayed
# This code cell contains only comments
```

**Output:** None — comments starting with `#` are ignored by the Python interpreter. They exist only to document code intent.

---

## Task 4: Adding Comments

```python
# This cell displays "I am using Python."
print("I am using Python.")
```

**Output:** `I am using Python.`

---

## Task 5: Writing a print() Statement

```python
print("I am a security analyst.")
```

**Output:** `I am a security analyst.`

---

## Task 6: Another print() Statement

```python
print("Python is useful for security!")
```

**Output:** `Python is useful for security!`

---

## Task 7: Combined print() Statements

```python
print("Hello world!")
print("I am using Python.")
print("I am a security analyst.")
print("Python is useful for security!")
```

**Output:**
```
Hello world!
I am using Python.
I am a security analyst.
Python is useful for security!
```

Each `print()` call outputs on a new line, executing sequentially from top to bottom.

---

## Key Takeaways

- Python's `print()` function displays strings to the screen — fundamental for outputting security analysis results
- Comments (`#`) document code intent without affecting execution — essential for team collaboration
- Notebook environments combine markdown and code cells — ideal for security analysis workflows
- Python is a powerful language for automating security tasks, analyzing logs, and building security tools
